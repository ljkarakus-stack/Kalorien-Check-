# jamileo Kalorien-Check

Kalorien, Protein, Kohlenhydrate, Fett, Wasser und Gewicht einfach tracken – mit den Lebensmitteln aus den Kalorien-Checks von [@jamileo__](https://www.instagram.com/jamileo__/).

- Tagesziel-Rechner, frei anpassbar
- Lebensmittel-Liste, fertige Tagespläne, manuelle Eingabe und Barcode-Scanner (Daten: Open Food Facts, ODbL)
- Wochenübersicht und Gewichtsverlauf
- Installierbar als App, funktioniert offline
- Alle Daten bleiben auf dem eigenen Gerät, Export/Import als Datei

Alle Nährwerte sind Richtwerte. Die App ersetzt keine ärztliche oder ernährungsfachliche Beratung.

Schriften: Baloo 2 und Caveat Brush (SIL Open Font License). Barcode-Erkennung: [ZXing](https://github.com/zxing-js/browser) (MIT).
